Kabelos creates a private local link between nearby devices using Wi-Fi Direct. Once connected, the devices share one session for chat, file transfer, and diagnostics.

No internet, router, hotspot, account, or cloud service is required. The connection stays local between the participating devices.

Features:
- Simple onboarding with automatic setup checks
- Direct device-to-device connection over Wi-Fi Direct
- Send photos from your library or files with one tap
- Real-time chat between connected peers
- QR code pairing helper to identify devices
- Background service so you can receive files even when the app is closed
- Detailed device info and setup diagnostics
- Protocol v2 transport with UDP rendezvous

Optional advanced features (hideable in Settings):
- Low-latency Audio Link using libopus
- Built-in upload and download speed tests

The Android app can connect to another Android device running Kabelos. A separate Windows companion client is also available for Android-to-Windows workflows.

Requires Android 13 or newer.

Kabelos is designed for simple offline sharing between family members — just two devices and a few taps.
